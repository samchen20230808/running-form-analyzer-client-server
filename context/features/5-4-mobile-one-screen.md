# Feature 5.4 — 手機版核心一／核心二一屏顯示

## Status

`done`（實機待驗）

## Epic

Epic 5 — PWA 與手機版 UI（接 5.3；5.2 PWA 仍為 planned，互不依賴）

## Objective

5.3 的核心一、核心二在手機上各自高約 840px，必須上下捲動才能操作。目標：手機（≤ 639.98px）上，**切到核心一或核心二時，Logo＋常駐區＋該主題整個放進一個畫面，不用捲動頁面**；「分析」仍可下捲。

**已由使用者決定（「照建議」）**：

1. 核心一、核心二的設定項收進「⚙」彈出面板（用完收起、恢復正常）：夜間增亮、方向、機位、1:1 即時驅動、圖層（徐國峰虛線／水滴軌跡）、骨架速度、骨架圖例。
2. 常駐區的身高／步幅／步頻／配速**不做**單行摘要（量測後若仍放不下才另議）。
3. 編號 5.4，新 Feature。

**行為不變**：`lib/**`、`app/**`、API、既有 JS 邏輯、桌面與平板（≥ 640px）版面、`APP_CONFIG`、baseline（103／361ms／96）。

## 設計

### 高度分配（`#coreSection`）

- JS 於進入手機模式與 `resize` 時算出被佔用高度 `--chrome-h = header + #mobileBar + 16`，設到 `#coreSection` 並加 `data-fit`；CSS：`height: calc(100svh - var(--chrome-h))`（前一行 `100vh` 作 fallback；svh 不隨網址列收合變動）、`min-height: 420px`（矮螢幕保底：頁面略可捲）、單列 `minmax(0, 1fr)`，卡片 `height: 100%; min-height: 0`。
- `#appMain` 手機上下內距縮為 8px。
- 卡片內：固定高度的標題與控制列，影片／畫布區 `flex: 1; min-height: 0`，等比縮放。

### 核心一

- 標題列只留一行：⚙｜📂 上傳影片｜📹 拍攝影片（隱藏標題與狀態點）。
- 夜間增亮、方向、機位、1:1 即時驅動移入設定面板。
- AI 狀態 HUD 改為影片上方的半透明疊層（絕對定位，字級縮小）。
- 空狀態：隱藏圖示與長說明，保留標題與按鈕。
- 控制列：播放／上一／下一（文字縮成圖示）／速度同一行，進度條一行，「智慧擷取」按鈕滿寬；隱藏 💡 說明。

### 核心二

- 整個標題列隱藏（圖層按鈕移入設定面板）；⚙ 放在控制列。
- 骨架 HUD 壓成單行（隱藏 `#simStateLabel`）；圖例移入設定面板。
- 控制列：播放／上一／下一／⚙ 同一行，進度條一行；速度切換移入設定面板。
- 四相位改為一排四顆，隱藏副標，標籤與百分比直排。

### ⚙ 設定面板（`#coreSettings`）

- 底部彈出（fixed、含背景遮罩）；依目前主題顯示 `#coreSettingsOne` 或 `#coreSettingsTwo`；「完成」鈕、點遮罩、Esc、切換主題皆關閉。
- 沿用 5.3 做法：`mobile-shell.js` 進入手機時把既有節點（ID 與事件不變）搬進面板，離開時搬回原位；桌面不動。
- 搬走的按鈕以 `#coreSettings` 前綴補回 44px 觸控規則與 16px 字級。

## 驗證

1. `npm run build`、`npm run lint`、`REQUIRE_BASELINE=1 npm test`（基準不變）。
2. Playwright：390×700、390×844、360×740、360×600 於核心一、核心二：主題卡片底部 ≤ 視窗高（360×600 允許保底略捲）、無橫向溢出、可見控制項 ≥ 44px（range 除外）、console 0 error。
3. 互動：⚙ 面板開關（完成、遮罩、Esc、切換主題）；方向／機位／夜間增亮／圖層／速度在面板內仍可操作並生效；影片擷取 analyze／derive 200；匯入 walk JSON 步頻 103；視窗 1440↔390↔768 縮放節點搬移冪等；桌面與平板版面不變。

## 風險與限制

- 360×600 等矮螢幕仍可能略捲（保底 `min-height: 420px`）。
- 瀏覽器網址列收合會改變 `innerHeight`，高度可能跳一次。
- 骨架畫布縮小後細節變小（等比縮放）；影片橫式時留白增加。
- 設定項多一次點擊；實機待使用者驗。
